What is a Promise?

                    
A Promise represents a result that may be available now, later, or not at all. It has three states: pending, fulfilled, or rejected.

                    
Use Promises for asynchronous work such as fetching data from an API, waiting for a timer, or reading a file. They let your page stay responsive while that work is happening.

                    
function getStudyTip() {
  return new Promise((resolve) => {
    setTimeout(() => resolve("Review for 10 minutes"), 800);
  });
}

getStudyTip().then((tip) => console.log(tip));

                    
Here, resolve supplies the result and .then() handles it when ready. Use .catch() to handle a rejected Promise.
